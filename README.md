# WAAAGH! Battery — виджет для внешнего экрана Galaxy Z Flip 4

Техническое задание: [WAAAGH-Battery-Flip4.md](WAAAGH-Battery-Flip4.md). APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Внешний экран: только баннер, всегда включён

Samsung не даёт сторонним приложениям рисовать поверх внешнего экрана Flip 4 (оверлей служб специальных возможностей не получает токен, а дисплей скрыт из `getDisplays()`), но разрешает запускать на нём activity. Поэтому служба специальных возможностей `cover/CoverOverlayService` держит на дисплее 1 полноэкранный `cover/CoverActivity` с одним баннером:

- поверх экрана блокировки обложки (`showWhenLocked`), `FLAG_KEEP_SCREEN_ON`;
- при закрытом телефоне (датчик угла шарнира < 30°) будит экран сам, проверка каждые 5 с;
- раз в минуту сдвигает картинку на 2 px против выгорания AMOLED;
- двойной тап скрывает баннер на 10 с (например, чтобы ответить на звонок).

Включение: тестовый экран → «Внешний экран: только баннер, всегда включён» → включить службу «WAAAGH! на внешнем экране».

## Что внутри

| Часть | Файлы |
|---|---|
| Подготовка графики (Python, один раз) | `tools/segment.py` — из `source/waaagh_banner.png` маски 7 символов и челюсти (watershed + ручные маркеры на стыках), `tools/make_assets.py` — основа без букв с закрашенной челюстью, слой букв, карта символов, эталонные превью |
| Ассеты | `app/src/main/assets/banner/` (`letters_orig.png`, `symbols.png`, `meta.txt`), `res/drawable-nodpi/banner_base.png` |
| Логика без Android | `core/BannerMath.kt` — шкала, сталь и красная краска из исходных пикселей, общий рендерер; `core/BannerState.kt` — режимы звонок > уведомление > батарея, рисунок тряски |
| Android | `BannerController` (хаб событий), `cover/` (баннер на внешнем экране), `widget/` (RemoteViews, ViewFlipper или ручная тряска), `events/` (уведомления, звонки, фоновая служба, загрузка), `ui/TestActivity` (тестовый экран) |
| Тесты | `app/src/test/...`: шкала, сценарии событий (этап 4 из промпта), рендер реальных ассетов → `app/build/render-test/*.png`, сверка с эталоном на Python |

Шкала: символ `i` заливается снизу вверх на `clamp((заряд − 10i)/10)`, выше 70% оттенок краски идёт к красному (зелёный → жёлтый → оранжевый → красный) с долей `(заряд − 70)/30`. Тени, сколы и блики сохраняются: сталь считается из яркости, красный — заменой оттенка при тех же насыщенности и яркости.

## Сборка

Установите JDK 17 и Android SDK, задайте `JAVA_HOME` и `ANDROID_HOME` для своей системы.

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
```

```powershell
& "$env:ANDROID_HOME\platform-tools\adb.exe" install -r app\build\outputs\apk\debug\app-debug.apk
```

## Проверка на телефоне

1. В приложении нажать «Уведомления» (выдать доступ), «Звонки» (разрешить), «Без ограничений батареи».
2. Добавить виджет «WAAAGH! заряд» на внешний экран (CoverScreen OS или другой лаунчер внешнего экрана).
3. Этап 1: видимость на странице виджета, на странице часов, при погашенном экране, при входящем звонке.
4. Этап 2: слайдер «Тестовый заряд» → 5, 35, 65, 70, 85, 100%, затем вниз.
5. Этап 3: «Настоящее уведомление» трясёт, «Обновить его» — нет. Звонок с другого телефона: принять, отклонить, пропустить.
6. Если на внешнем экране тряска не идёт — переключить «Тряска на виджете» на «Ручная».
7. Этап 4: тестовый заряд 5% → «Уведомление» → сразу «Входящий звонок» → слайдер 6% → «Завершить звонок»: W залита на 60%.
8. Строка «последнее обновление» внизу тестового экрана показывает, принял ли хост картинку.
