# WAAAGH! Battery — баннер заряда для Galaxy Z Flip 4

Техническое задание: [WAAAGH-Battery-Flip4.md](WAAAGH-Battery-Flip4.md). APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Внешний экран

Служба специальных возможностей `cover/CoverOverlayService` показывает `cover/CoverActivity` (только баннер) поверх штатной обложки Samsung, когда внешний экран включается и когда приходит новое уведомление. Тап по баннеру закрывает его — остаются часы, свайп влево к уведомлениям, вправо к музыке. Экран служба не будит и не держит, гаснет он по системному тайм-ауту. Samsung не даёт оверлеям токен на дисплее обложки и скрывает его из `getDisplays()`, поэтому используется activity с `setLaunchDisplayId(1)`.

Включение: тестовый экран → «Баннер на внешнем экране» → включить службу «WAAAGH! на внешнем экране».

## Что внутри

| Часть | Файлы |
|---|---|
| Подготовка графики (Python, один раз) | `tools/segment.py` — из `source/waaagh_banner.png` маски 7 символов и челюсти (watershed + ручные маркеры на стыках), `tools/make_assets.py` — основа без букв с закрашенной челюстью, слой букв, карта символов, эталонные превью |
| Ассеты | `app/src/main/assets/banner/` (`letters_orig.png`, `symbols.png`, `meta.txt`), `res/drawable-nodpi/banner_base.png` |
| Логика без Android | `core/BannerMath.kt` — шкала, сталь и красная краска из исходных пикселей, общий рендерер; `core/BannerState.kt` — режимы звонок > уведомление > батарея, рисунок тряски |
| Android | `BannerController` (хаб событий), `cover/` (баннер на обложке), `widget/` (RemoteViews, ViewFlipper или ручная тряска), `events/` (уведомления, звонки, фоновая служба, загрузка), `ui/TestActivity` (тестовый экран) |
| Тесты | `app/src/test/...`: шкала, сценарии событий (этап 4 технического задания), рендер реальных ассетов → `app/build/render-test/*.png`, сверка с эталоном на Python |

Шкала: символ `i` заливается снизу вверх на `clamp((заряд − 10i)/10)`, выше 70% оттенок краски идёт к красному (зелёный → жёлтый → оранжевый → красный) с долей `(заряд − 70)/30`. Тени, сколы и блики сохраняются: сталь считается из яркости, красный — заменой оттенка при тех же насыщенности и яркости.

## Сборка

Установите JDK 17 и Android SDK, задайте `JAVA_HOME` и `ANDROID_HOME` для своей системы.

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
```

```powershell
& "$env:ANDROID_HOME\platform-tools\adb.exe" install -r app\build\outputs\apk\debug\app-debug.apk
```

## Проверка на телефоне

1. В приложении нажать «Уведомления» (выдать доступ), «Звонки» (разрешить), «Без ограничений батареи».
2. «Баннер на внешнем экране» → включить службу «WAAAGH! на внешнем экране».
3. Закрыть телефон, тапнуть по внешнему экрану: появляется баннер; тап по баннеру — штатные часы, свайпы влево/вправо работают. Новое уведомление снова показывает баннер (красный, тряска).
4. Шкала: слайдер «Тестовый заряд» → 5, 35, 65, 70, 85, 100%, затем вниз.
5. События: «Настоящее уведомление» трясёт, «Обновить его» — нет. Звонок с другого телефона: принять, отклонить, пропустить.
6. Совмещение: тестовый заряд 5% → «Уведомление» → сразу «Входящий звонок» → слайдер 6% → «Завершить звонок»: W залита на 60%.
7. Виджет «WAAAGH! заряд» на главном экране: если тряска не идёт, переключить «Тряска на виджете» на «Ручная»; строка «последнее обновление» показывает, принял ли лаунчер картинку.
